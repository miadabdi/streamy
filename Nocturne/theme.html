Theme parameters
Ground
dark-first (scheme: mono, hue 22°; the accent is pinned to #ff4a32, chosen by the operator). A light theme is derived from the same token names under [data-theme="light"].
Fonts
Archivo / Archivo, JetBrains Mono for IDs, keys, counts and logs
Density
0.70× in studio and ops · 1.0× in the viewer (data-density="roomy")
Radius
6px
Layout
left
Dividers
none
Buttons
solid accent primary, outlined secondary
Interop
shadcn/ui variable aliases (--background, --primary, --ring…) mapped onto the tokens
Frame
none
Media
16:9 thumbnails (optional upload, derived fallback), 400×400 avatars with initials fallback
Icons
Streamy geometric set for video/live/ops, Phosphor for everything else

These values are the seed this system was derived from: styles.css, every page in this project and the guide in readme.md were built from them (the machine-readable copy is theme.json). If you retune the system by hand — palette, type, radii, spacing — do it in styles.css (the one place tokens live) and keep this page and theme.json in step so the record stays true. The data-theme-* attributes above mirror the ground / scheme / hue knobs for a future theme-controls surface; today they are documentation, nothing reads them.
